#  Doctor Appointment Reservation System

Уеб платформа за лесно запазване, управление и планиране на медицински часове при лекари и специалисти.

##  Използвани технологии и езици

* **Програмен език:** C#
* **Технология / Фреймуърк:** ASP.NET
* **База данни:** MySQL (за управление на потребители, лекари и резервации)
* **Стилизиране:** Custom CSS (модерен и адаптивен интерфейс)

##  Основни функционалности

* **Запазване на час:** Избор на дата, час и предпочитан медицински специалист.
* **Профили на лекари:** Преглед на специализации, графика и свободни часове.
* **Управление на резервациите:** Преглед и отмяна на записани часове.
* **База данни:** Сигурно съхранение на цялата информация в локална база данни.
